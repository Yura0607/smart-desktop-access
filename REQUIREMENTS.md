# Smart Desktop Access requirements

## Web client: full remote control from any browser

- The web version must give complete remote control of the customer's computer from a web page: live screen, mouse, keyboard, and everything else, not view-only.
- It must work from any browser with nothing to install: iPad, iPhone, Android phones, Mac and Windows (current Safari, Chrome, Edge, Firefox).
- Mouse: move, left/right/middle click, double-click, drag, wheel scroll. Touch devices map taps, long-press, two-finger scroll and pinch-zoom to mouse actions, with a trackpad-style mode.
- Keyboard: typing, special keys and shortcuts (Ctrl+Alt+Del, Ctrl/Cmd combinations, Esc, function keys), with an on-screen keyboard on touch devices.
- Session tools match the admin app where the browser allows it: clipboard, two-way file transfer, chat, voice, monitor switching, restart and lock.
- Sign-in is required before any session, over HTTPS only.
- This replaces the earlier rule that the web client is view-only and that all control happens in the admin app.

## Admin app

- Smart Desktop Access Admin (Windows, Mac, Android, iPhone/iPad) stays as it is.
